The mullender brand system

A minimal brand system for the personal site at mullender.com, with sibling identities for .nl and .dev. One font, one letter, one shape — differentiated by color to signal context. This page is the source of truth for logo, typography, color, usage, and asset downloads.

Body copy

Body text uses the browser's default sans-serif stack (system-ui, -apple-system, "Helvetica Neue", Arial, sans-serif). Comfortaa is reserved for the wordmark and section chrome — using it for body text sacrifices readability.

Bark · warm accent

Usage rules.

  • Site chrome uses moss-950 for backgrounds and stone-100 for text.
  • Links use moss-300; hover brightens to moss-200.
  • TLD accent colors (moss, orange, ocean) appear only in the wordmark's TLD text and in the corresponding favicon tile. Do not use them for buttons, borders, or body copy.
  • Bark is a small warm accent for e.g. star counts, badges, secondary metadata — never for headings.

Usage

do's and don'ts

Do

  • Use the correct color per TLD (moss for .com, orange for .nl, ocean for .dev).
  • Keep the corner radius at rx=22 in the 128 px viewBox (roughly 17% of the tile).
  • For adaptive icons on dark tab bars, use the outline variant.

Don't

  • Don't invent new colors. Use only the three sanctioned accents.
  • Don't swap the font. Comfortaa 700 is the mark — the m is the shape.
  • Don't rotate, skew, or add drop shadows.
  • Don't change the corner radius (no full-circle, no sharp corners).

Assets

SVG source · PNG export · ICO instructions

Source SVGs live in designs/assets/. Two variants of each favicon: source (uses Comfortaa via @import, editable — change the text and it re-renders), and outlined (the m baked as an SVG <path>, no font dependency, safe for tab-bar rendering / offline / embedding). The site uses the outlined version. Keep the source around for edits — regenerate the outlined file whenever the design changes.

Source vs. Outlined

Both files render identically in a browser with Comfortaa loaded (like this page). The difference shows up in environments that don't process @font-face inside SVG — some tab bars, image-based fetches, embedded viewers. The outlined version is bulletproof there; the source falls back to system-ui and looks slightly different.

Making favicon.ico

Download the 16, 32, and 48 px PNGs above, then combine into a multi-resolution ICO with ImageMagick: 

magick favicon-com-16.png favicon-com-32.png favicon-com-48.png favicon.ico

(Or drop the 512 px PNG into realfavicongenerator.net for a full multi-platform bundle including apple-touch-icon, manifest, and safari-pinned SVG.)
